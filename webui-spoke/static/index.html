Configure certified USB dongles, provisioning behavior, and VM template assignments.

        

        


          
          

            
Provisioning Behavior

            

              
              
            

            When enabled, if the preferred dongle type runs out, remaining certified dongles of the other type will be provisioned automatically using their own sim profile.
            

              

                
                
                Preferred dongle type for auto-provisioning. Choose Any to allow either certified type.
              

              

                
                
                How long a dongle can be absent before its VM is destroyed.
              

            

          


          
          

            
Parallel Provisioning

            

              

                
                
                Number of VMs to reclone or provision simultaneously. 1 = sequential (safe). Increase for faster fleet operations.
              

            

          


          

            
VM Templates

            

              

                
                
                Individual VMIDs or ranges. The lowest valid template match is used first.
              

              

                
                
                Must not overlap with VM Image 1.
              

              

                
                
                Image 2 gets the remainder.

📡 Push WiFi Auth Fix to All Clients

          
Dispatches an Update Now command to every registered client. This re-deploys the polkit rule and kills nm-applet, fixing recurring WiFi authentication popups.
